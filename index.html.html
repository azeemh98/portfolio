01 · Live Product

SoulCalc — Print Rate Calculator

A multi-product quotation tool built for Soulful Events, covering Booklets, Card Sheets, Stickers, and Certificates. Clients and staff get instant, accurate quotes — while the actual pricing logic stays fully hidden and secure.

  • ✓ Handles 4 distinct product types with different pricing rules — offset and digital booklet pricing calibrated against real historical job data
  • ✓ Booklet pricing is computed server-side via a Supabase Edge Function, so the formula never reaches the browser
  • ✓ Automatic GST handling on paper cost, with clean GST-exclusive client-facing quotes
  • ✓ Internal cost breakdowns (paper, machine, binding, plate, discounts) stay hidden — clients see only the final price
  • ✓ Role-based accounts for admin and staff, with 3-month quote validity built in

02 · Production Tool

PrintPress — Stock & Order Management

A self-contained stock and order management app built for a printing press business, designed to track materials and orders through their full production lifecycle without needing a heavy backend team to maintain it.

  • ✓ Single-file, self-contained app architecture — lightweight to deploy and maintain
  • ✓ Connected to a live Supabase backend for real-time stock and order data
  • ✓ Full production lifecycle tracking, from order intake to completion
  • ✓ Built-in demo mode for onboarding and walkthroughs without touching live data
